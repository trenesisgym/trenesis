# How the site is built

Every page is generated by `tools/build_site.py` from the files in `content/`:

| To change | Edit |
| --- | --- |
| An article | `content/articles/<slug>.md` |
| About or Privacy | `content/pages/about.md` or `privacy.md` (text in `[[double brackets]]` shows as a highlighted gap) |
| Equipment, Supplements, Accessories advice | `content/gear/<name>.html` |
| Product picks per country | `assets/catalogs.js` (no rebuild needed) |
| Homepage, Training, Nutrition | `content/hand/index.html`, `training.html`, `nutrition.html` (the page content between header and footer; the two comment lines at the top set the title and description) |
| The old Articles page | `content/hand/articles-redirect.html` (copied as-is; it forwards to the homepage) |
| Header menu, footer, country picker | `header()`, `footer()` and `country_picker()` in `tools/build_site.py` |
| Questions & answers page | `content/hand/faq.html` (one `<details>` per question; the search and Google's FAQ data update automatically) |
| Workout logbook | Built automatically from the workout tables in the plan articles (`tools/logbook.py`). Change a plan's table and the logbook follows. To add a new plan, add it to `PLANS` in that file. The page itself is `tools/logbook_page.html`; the exercise library and the Push/Pull/Legs template are in `tools/logbook.py` |
| Calorie calculator | `tools/calculator.py` (Mifflin-St Jeor; the rules are listed at the top of the file) |
| Colours, fonts, spacing | `assets/styles.css`, and `assets/revision.css` for the newer design (it loads last, so it wins). No rebuild needed |

Then rebuild:

```
pip install markdown        # once
python3 tools/build_site.py
```

Commit the content file and the regenerated `.html` files together. Don't edit the
generated `.html` files directly: the next build overwrites them. If you redesign a page
by hand (or with Codex), put its content into `content/hand/` instead, or ask Claude to
fold the change into the build.

To add an article: copy an existing `.md` file, change its header, and add its slug to
`ORDER` in `tools/build_site.py` (that list sets the reading order).

## Link-preview images

Each article has its own preview image in `assets/img/og/`, used when the link is shared
on Instagram, WhatsApp, TikTok and so on. After adding an article, run
`node tools/make_share_images.js` (needs Node and `npm i playwright`), then rebuild.
Articles without an image fall back to `assets/img/share.jpg`.

## Calculator

`calculator.html` comes from `tools/calculator.py`. Its numbers follow the articles:
maintenance = bodyweight x 28-40 kcal/kg by activity, fat loss 10-20% below that,
muscle gain +200-300 kcal, protein 1.6-2.2 g/kg. It never shows a fat-loss target
when someone's BMI is under 18.5.

## Plan finder, start page, 404 and article extras

`tools/parts.py` holds the plan finder (`find-your-plan.html`), the link-in-bio page
(`start.html`, for Instagram and TikTok bios), the 404 page, and the article extras:
key takeaways (the `takeaways:` line in each article's header, three points split by ` | `),
table of contents, breadcrumbs, author box and the plan/calculator boxes.
