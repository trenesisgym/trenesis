# Locally hosted fonts

These unmodified font files were downloaded from the Google Fonts CSS API on 17 November 2026. They are served from this repository; visitors do not contact Google to load fonts.

`fonts.css` preserves the upstream Unicode subsets, weight ranges and `font-display: swap`. It includes Inter and all three heading options supported by `tools/build_site.py`; browsers only load the subsets and families used on the page.

Each family is distributed under the SIL Open Font License 1.1. The corresponding `*-OFL.txt` files contain its copyright notice and license. License sources: https://github.com/google/fonts/tree/main/ofl (inter, barlowcondensed, archivo, bricolagegrotesque).
